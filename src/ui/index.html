Breathe with the sun?

  • The camera is on only while an agent run is in progress and this card is up.
  • Video is processed on this computer by the Presage SmartSpectra SDK. Exhale never saves or uploads it.
  • The SDK checks your API key with Presage. Exhale switches its usage telemetry off.
  • Nothing is kept unless you turn on history.
  • A breathing exercise, not a medical device.

How it works

  1. Connect your agent

    For Claude Code, copy these hooks into ~/.claude/settings.json. They tell Exhale when a prompt starts and when Claude stops.

    For any other command, wrap it: exhale run -- npm test

  2. Keep working

    Runs shorter than 10 seconds are ignored. For longer ones the card appears, and asks before the camera turns on the first time.

  3. Breathe with the sun

    When the agent finishes, the camera turns off and the card shows a short recap of the run.

Camera

Pick the camera that faces you. An iPhone works too (Continuity Camera): keep it near your Mac and it shows up here.
